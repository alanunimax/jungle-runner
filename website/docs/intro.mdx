# Jungle Runner

Jogo 2D de corrida infinita desenvolvido em Python com Pygame-CE,
como parte do Projeto Prático Integrado.

## Como executar

1. Crie e ative o ambiente virtual
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python main.py`

## Controles

| Tecla | Ação |
|---|---|
| Espaço | Pular |
| ESC | Sair |
